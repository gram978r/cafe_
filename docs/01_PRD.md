# 프렙 카페 운영 분석 프로그램 PRD

## 사용 목적

프렙 카페의 판매·비용·재고 기록을 한곳에서 관리하고, 매장 운영자가 다음을 빠르게 확인할 수 있도록 한다.

- 판매 기록을 입력하고 수정·삭제한다.
- 일·주·월별 판매 실적을 확인한다.
- 메뉴별 변동 수익성을 비교한다. 변동 수익성은 판매량에 따라 달라지는 비용을 반영한 수익성이다.
- 선택한 기간의 실제 손익을 확인한다. 손익은 매출에서 비용을 뺀 결과다.
- 재료별 잔량과 실사 기록을 확인한다. 실사는 실제로 세어 확인한 재고다.

이번 실습의 목표는 **판매 기록 입력 → 메뉴 수익성 확인 → 실제 손익과 재료 잔량 확인**으로 이어지는 핵심 흐름을 완성하는 것이다.

## 자료의 종류·기간·단위·중복 주의사항

### 자료에서 확인한 사실

- 자료는 가상 매장인 프렙 카페의 기록이다.
- 기록 기간은 2025-07-01부터 2026-09-18까지다.
- 영업 달력은 2025-07-01부터 2026-09-30까지 457일이지만, 2026-09-19부터 2026-09-30까지는 기록이 완성되지 않았다.
- 금액은 원화이며 부가세 제외 금액이다.
- 재료 수량 단위는 g, ml, 개다.
- 엑셀과 JSON은 같은 기록을 담은 두 가지 형식이다. 같은 자료를 한 번만 가져와야 한다.

| 자료 | 기록 수 | 주요 내용 |
|---|---:|---|
| 공급사 | 3 | 공급사 ID와 이름 |
| 재료 | 11 | 재료명, 기준 단위, 구매 용량, 기본 가격, 납기·안전재고 일수 |
| 메뉴 | 8 | 메뉴명, 판매 기준가, 분류, 레시피 버전 |
| 레시피 | 22 | 메뉴 1개에 필요한 재료와 사용량 |
| 재료가격이력 | 33 | 적용 시작일별 구매 가격과 구매 용량 |
| 영업달력 | 457 | 영업 여부, 마감 여부, 날씨, 메모 |
| 판매기록 | 6,112 | 일자·메뉴·판매채널별 판매 수량, 할인, 매출, 수수료, 당시 원가 |
| 초기재고 | 11 | 첫 영업 시작 전 재료 수량 |
| 재고기록 | 1,515 | 입고, 폐기, 실사조정 기록 |
| 월비용계획 | 120 | 월별 비용 항목과 금액 |
| 비용기록 | 3,560 | 날짜별 비용 항목과 금액 |
| 자료정보 | 10 | 매장명, 출처, 통화, 시작일, 마감일 등 |

### 기획 시 주의사항

- 판매기록은 주문 건수가 아니라 일자·메뉴·판매채널별 집계 기록이다.
- 구매 가격은 구매 용량 전체의 가격이고, 레시피 사용량은 메뉴 1개 기준이다.
- 판매 당시 단가, 할인, 순매출, 결제 수수료, 식재료 원가, 포장 원가는 해당 판매 시점의 기록이다.
- 레시피 적용 채널이 비어 있으면 모든 채널에 적용되고, 포장으로 표시된 재료는 포장 판매에만 적용된다.
- 재고 증감 수량은 입고가 양수이고 폐기가 음수다. 실사조정은 양수와 음수가 모두 가능하며, 실측수량은 실제로 센 수량이다.
- 월비용계획과 비용기록은 같은 비용을 월 단위와 일 단위로 표현한 자료다. 두 자료를 별도 지출로 더하면 안 된다.
- 빈칸은 해당 없음 또는 미입력일 수 있으므로 0과 구분해야 한다.
- 아직 마감하지 않은 미래 날짜를 판매량 0으로 처리하면 안 된다.
- 연간 집계는 전체 연도가 아니라 자료가 있는 일부 기간만 포함할 수 있다.
- 자료에 없는 수익성 분류, 예상 손익 방식, 비용 배분, 재고 처리 정책은 이미 합의된 것으로 보지 않는다.

## 사용자와 사용 순서

### 사용자

주 사용자는 카페 운영자 또는 매장 관리자다. 사용자 계정과 권한을 나누는 정책은 아직 정하지 않는다.

### 수업 중 핵심 사용 순서

1. 운영자가 판매 기록을 입력한다.
2. 잘못 입력한 판매 기록을 수정하거나 삭제한다.
3. 일·주·월 중 하나의 기간을 선택해 판매 실적을 확인한다.
4. 메뉴별 변동 수익성을 비교한다.
5. 같은 기간의 실제 손익을 확인한다.
6. 재료별 잔량과 최신 실사 기록을 확인한다.
7. 입력 오류가 있으면 기록을 수정하고 결과가 다시 반영되는지 확인한다.

## 필수 기능

### 수업 중 구현 범위

#### 1. 판매 기록 관리

- 판매 일자, 메뉴, 판매채널, 판매 수량, 판매 금액과 할인 등 자료에 있는 판매 기록을 입력한다.
- 기존 판매 기록을 수정한다.
- 잘못된 판매 기록을 삭제한다.
- 필수값 누락, 숫자가 아닌 수량, 허용되지 않는 음수 등 기본 입력 오류를 알려준다.
- 저장한 기록이 다시 조회될 수 있어야 한다.

#### 2. 일·주·월 실적 조회

- 일·주·월 단위로 판매 실적을 조회한다.
- 마감하지 않은 미래 날짜는 실적이 없는 날과 구분한다.
- 선택한 기간에 포함되는 판매 기록만 집계한다.

#### 3. 메뉴별 변동 수익성 조회

- 메뉴별 순매출을 비교한다.
- 판매 당시 기록된 식재료 원가, 포장 원가, 결제 수수료를 변동비로 반영한다.
- 메뉴별 수익성 금액과 판매량을 확인한다.
- 임대료·인건비 등 고정비를 메뉴별로 임의 배분하지 않는다.
- 원가나 수수료 기록이 없는 경우 실제 0인지 미입력인지 구분한다.

#### 4. 실제 손익 조회

- 선택한 일·주·월 기간의 판매 실적과 비용기록을 바탕으로 실제 손익을 확인한다.
- 비용기록은 한 번만 반영한다.
- 월비용계획은 수업 중 예상 손익 계산에 사용하지 않는다.
- 실제 손익과 비용 내역을 구분해 확인할 수 있어야 한다.

#### 5. 재료 잔량 조회

- 재료 11개의 단위와 잔량을 확인한다.
- 초기재고, 입고, 폐기, 실사조정, 판매와 레시피에 따른 사용량을 구분해 확인할 수 있어야 한다.
- 최신 실사수량이 있는 경우 계산상 잔량과 구분한다.
- g, ml, 개를 서로 합쳐 계산하지 않는다.

### 수업 후 확장 범위

- 비용기록 입력·수정·삭제
- 엑셀 양식 내려받기
- 엑셀 또는 JSON 기록 가져오기
- 중복 가져오기 방지와 가져오기 결과 검토
- 재료의 입고·폐기·실사조정 직접 입력
- 필요한 발주량 참고
- 분기·반기·연간 조회
- 예상 손익 조회
- 저장 데이터의 백업과 복원
- 메뉴별 고정비 배분이나 추가 수익성 분류

## 제외 기능

이번 4시간 실습에서는 다음을 구현하지 않는다.

- 예상 손익의 계산 방식 확정 및 구현
- 분기·반기·연간 집계
- 비용기록 직접 수정·삭제
- 엑셀 양식 생성 및 엑셀·JSON 가져오기
- 재고 변동 기록 직접 입력
- 발주량 자동 계산
- 백업·복원
- 사용자 계정, 권한, 다중 매장 관리
- 세금 신고, 회계 장부, 결제 시스템 연동
- 기술 선택, 상세 계산식, 화면 배치와 시각 디자인, 코드, 배포 방식의 확정

## 완료 기준

### 핵심 흐름 완료 기준

- 운영자가 새 판매 기록을 입력하고 저장할 수 있다.
- 운영자가 판매 기록을 수정하거나 삭제할 수 있다.
- 잘못된 필수값이나 허용되지 않는 입력을 저장하지 않고 이유를 알 수 있다.
- 페이지를 다시 열거나 새로 조회해도 저장된 판매 기록이 유지된다.
- 일·주·월 기간을 바꾸면 해당 기간의 판매 실적만 표시된다.
- 마감하지 않은 미래 날짜가 판매량 0으로 잘못 집계되지 않는다.
- 메뉴별 수익성 결과가 판매 기록과 당시 원가·수수료 기록에 맞게 바뀐다.
- 판매 기록을 추가·수정·삭제했을 때 관련 수익성 결과가 함께 바뀐다.
- 실제 손익이 선택한 기간의 판매와 비용기록을 기준으로 표시된다.
- 월비용계획과 비용기록이 중복으로 더해지지 않는다.
- 재료별 단위가 유지되고, 재료 잔량과 최신 실사수량이 구분된다.
- 대표 메뉴, 기간 경계일, 판매량 0, 빈 원가, 빈 비용, 폐기와 실사조정 사례를 검사한다.
- 합계와 세부 기록이 맞지 않거나 필수 데이터가 없는 경우 결과를 0으로 숨기지 않고 확인할 수 있다.

### 실습 결과물 완료 기준

- 수업 중 구현 범위와 수업 후 확장 범위가 문서와 구현 결과에서 구분된다.
- 사용자가 핵심 흐름을 처음부터 끝까지 시연할 수 있다.
- 기본 오류 처리와 데이터 저장 검증을 완료한다.
- 자료의 기간·단위·중복 주의사항이 프로그램 사용 기준에 반영된다.
- 수업 중 구현하지 않은 기능은 완료된 것처럼 표시하지 않는다.

## 미정 사항

아래 항목은 자료만으로 결정할 수 없으므로 임의로 확정하지 않는다.

- 주간 조회의 시작 요일
- 회계연도와 연간 조회의 기준
- 메뉴 수익성을 금액만 표시할지, 수익률이나 등급으로 분류할지
- 예상 손익의 판매량 전망 기간과 전망 방법
- 월비용계획을 예상 손익에 반영하는 방식
- 비용기록의 인식 기준과 비용 수정 이력 관리 방식
- 판매에 따른 재료 사용량을 계산상 잔량에 반영하는 정확한 정책
- 실사수량을 계산상 잔량에 반영하는 시점과 우선순위
- 발주량의 기준 기간, 납기·안전재고 일수 활용 방식, 구매 포장 단위 올림 여부
- 엑셀 양식의 열 구성과 가져오기 중복 판정 기준
- JSON 가져오기를 허용할지 여부
- 백업 파일의 범위와 복원 시 기존 자료 처리 방식
- 메뉴·레시피·재료 가격 변경 이력의 관리 방식
- 사용자 계정과 권한 구분
