## 사용자 화면 확인

상태: 사용자 확인 완료

브라우저를 열어 다음 순서로 확인한다.

1. 로그인 화면에서 기본 데모 운영자 정보로 `운영 자료 열기`를 누른다.
   - 예상 결과: 판매 기록 관리 화면이 열리고 `서버 저장 자료` 표기가 보인다.
2. 집계일자가 `2026-09-18`인지 확인한다.
   - 예상 결과: 저장된 판매 기록 행과 메뉴명이 보이고, 상단 수량·순매출 요약이 채워진다.
3. `포장 (To-Go)` 채널을 누른다.
   - 예상 결과: 표의 모든 행이 `포장` 채널로만 좁혀진다.
4. 메뉴명 검색에 `아메리카노`를 입력한다.
   - 예상 결과: 아메리카노 판매 행만 남는다.
5. 브라우저 새로고침을 한다.
   - 예상 결과: 로그인 상태가 유지되고, 집계일자·검색 조건·서버에서 다시 읽은 판매 자료가 보인다.

사용자 확인 완료: 로그인 후 자료 조회, 채널·메뉴 필터, 새로고침 유지가 문제없이 동작했다. 이에 따라 EPIC 1을 개발계획에서 완료로 표시했다.

### 사용자 화면 확인

상태: 사용자 확인 완료

1. `신규 판매 기록`을 누르고 아메리카노·`배달(Delivery)`, 수량 2, 단가 4,500원, 할인 500원을 입력한다.
   - 예상 결과: 예상 순매출이 `₩8,500`으로 표시된다.
2. `저장하기`를 누른다.
   - 예상 결과: 판매 목록에 새 기록이 생기고 순매출이 `₩8,500`이다.
3. 새로 생긴 기록에서 `수정`을 누르고 수량을 3으로 바꾼다.
   - 예상 결과: 순매출이 `₩13,000`으로 바뀐다.
4. `실적 조회`에서 일간·주간·월간을 차례로 누른다.
   - 예상 결과: 일간은 기준일, 주간은 월요일~일요일, 월간은 해당 월의 1일~말일 범위로 표시된다.
5. 기준일을 `2026-09-18`로 두고 주간 조회를 확인한다.
   - 예상 결과: `2026-09-14 ~ 2026-09-20`이 보이고, 9월 19·20일은 `미마감`과 `—`로 표시된다.
6. 판매 기록 화면으로 돌아가 같은 기록의 수량을 다시 2개로 수정한다.
   - 예상 결과: 선택 기간의 수량·순매출이 함께 바뀐다.
7. 같은 기록의 `삭제`를 누르고 삭제 확인을 승인한다.
   - 예상 결과: 목록과 해당 기간 실적에서 기록이 사라진다.
8. 브라우저를 새로고침한다.
   - 예상 결과: 저장된 판매 기록과 현재 실적 기간 선택이 다시 조회된다.

실행 명령: `npm test` (EPIC 1·2·3 총 10개 통과)

### 사용자 화면 확인

상태: 사용자 확인 완료

현재 브라우저는 `손익·재고` 화면에 열려 있다.

1. `수익성` 메뉴를 누르고 기준일 `2026-09-18`, 채널 `전체 채널`을 확인한다.
   - 예상 결과: 메뉴별 순매출·식재료비·포장비·결제수수료·변동 수익과 `정상 기록됨` 상태가 표시된다.
2. 수익성 화면에서 채널을 `매장(홀)`로 바꾼다.
   - 예상 결과: 매장 판매만 집계되고 포장비가 반영되지 않는다.
3. 채널을 `포장(To-Go)`로 바꾼다.
   - 예상 결과: 포장 판매만 집계되고 포장비가 식재료비와 별도로 표시된다.
4. `손익·재고` 메뉴에서 일간 기준일 `2026-09-18`을 확인한다.
   - 예상 결과: 순매출 `₩671,900`, 변동비 `₩182,031.68`, 실제 비용 `₩211,000`, 실제 영업이익 `₩278,868.32`가 표시된다.
5. 실제 비용 상세를 확인한다.
   - 예상 결과: 실제 비용 기록만 합산되고, 월별 비용 계획은 참고 금액으로만 표시되며 손익에 중복 합산되지 않는다.
6. 재료 표에서 원두와 우유를 확인한다.
   - 예상 결과: 원두는 `g`, 우유는 `ml`로 분리되고 서로 합쳐지지 않는다. 원두는 계산 잔량 `4,280g`, 실사 `3,780g`, 차이 `-500g`으로 표시된다.
7. `차이 있음` 필터를 누른다.
   - 예상 결과: 실사 수량과 계산 잔량이 다른 재료만 표시된다.
8. EPIC 2 판매 기록에서 한 메뉴의 수량을 수정한 뒤 수익성·손익·재고 화면을 다시 연다.
   - 예상 결과: 해당 메뉴 변동 수익, 실제 영업이익, 관련 재료 판매 사용량과 계산 잔량이 함께 바뀐다.
9. 브라우저를 새로고침한다.
   - 예상 결과: 선택한 기간과 서버에서 다시 계산한 수익성·손익·재고 결과가 유지된다.
